# First Version Acceptance Test

Use Android Chrome over HTTPS.

- [ ] Page opens and the dark Home screen is usable in portrait.
- [ ] Microphone permission can be granted.
- [ ] Calibration runs for 12 seconds and saves a pitch center.
- [ ] Four profiles are selectable.
- [ ] Regality slider changes from 0–100 and warns at high values.
- [ ] A 30–90 second exercise starts.
- [ ] Green target contour is visible.
- [ ] Blue live pitch trace appears while speaking.
- [ ] Moving playhead crosses the game field.
- [ ] Feedback changes during performance.
- [ ] Combo increases when pitch stays near target and can break on large misses.
- [ ] Scorecard appears at the end.
- [ ] Naturalness is present as a major score.
- [ ] Mimic Mode can play a synthesized original reference sentence.
- [ ] Mimic recording overlays the user's contour and produces a match score.
- [ ] Multiple drills can be launched.
- [ ] Progress chart updates after completed rounds.
- [ ] Closing/reopening preserves calibration and progress.
- [ ] Add-to-home-screen / Install is offered when the hosting/browser conditions allow PWA installation.
